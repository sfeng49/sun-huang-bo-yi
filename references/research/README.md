## 公开包包含什么

|内容|数量与范围|
|---|---|
|研究报告|1篇，含来源脚注|
|专题笔记|4篇|
|时间线与证据表|各1份|
|来源卡|33张，其中28项曾核读，5项仅线索|
|来源目录|Markdown和JSON各1份|
|第三方全文与原始媒体|不随公开包再分发|

来源卡是摘要，不是原文。查看原文请使用各卡提供的原始链接；页面是否仍可访问及是否被编辑，需要重新确认。公开打包没有重新核读全部网站，也未补齐原研究的缺口。

这些研究记录比较作者与社区的历史表达；实际咨询以[Skill入口](../../SKILL.md)的用户定义为准。二者的差异有意保留，不伪造统一原义。
