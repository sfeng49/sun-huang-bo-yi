# 孙黄薄抑论

**四个视角，一套行动方案。** 把现实问题交给 AI，分别从孙学、黄毛、薄肌、性压抑四个方向分析，再给出能一起执行的建议，并通过关键追问完善判断。

[下载 Skill](https://github.com/sfeng49/sun-huang-bo-yi/releases/latest) · [核心指令](SKILL.md) · [回答示例](references/response-examples.md) · [研究资料](references/research/README.md)

## 四个方向

|视角|关注什么|会怎样追问|
|---|---|---|
|**孙 · 资源归己**|让资源、机会、收入与成果流向自己；用未来回报叙事争取对方投入|怎样让自己成为受益者？对方为什么愿意现在投入？|
|**黄 · 勇敢争取**|表达真实喜好、观点与要求，敢于争取利益|你真正想要什么？是什么让你不敢说？|
|**薄 · 自律吸引**|保持自律、身材与吸引力，持续建设自己|你是在提升自己，还是依靠服从别人的要求证明价值？|
|**抑 · 不为性妥协**|不因担心失去性或亲密机会而放弃意愿与底线|如果不担心失去这段亲密机会，你还会答应吗？|

这里采用的是项目发起人指定的演绎框架。它有意提炼网络话语中鲜明的行动方向，不代表相关人物的共同声明或经过验证的普遍规律。黄毛不归为孙宇晨发明；薄肌也不指搏击技术。

## 安装

下载 Release 中的 `sun-huang-bo-yi-v2.2.0.zip`，解压后把整个 `sun-huang-bo-yi` 文件夹放到 `~/.codex/skills/`。若已有同名 Skill，可先将旧版本移出该目录再替换。

也可以在尚未安装时克隆：

```bash
git clone https://github.com/sfeng49/sun-huang-bo-yi.git ~/.codex/skills/sun-huang-bo-yi
```

在新会话中调用：

```text
使用 $sun-huang-bo-yi 分析：对方提出了一个让我不舒服的要求，我该怎么办？
```

它是文本型 Skill，无须配置 API Key，也不依赖仓库内的可执行程序。其他支持加载 `SKILL.md` 的工具也可使用核心指令；具体安装目录按对应工具设置。

## 回答会是什么样

默认约 450—700 个汉字，依次给出四个视角、综合建议和必要的关键追问。

- 四个分析保留各自方向，不提前合并成同一套泛泛建议。
- 综合时选择能同时执行的动作；有冲突就说明取舍和条件。
- 信息不足时先给暂定建议，再问 2—3 个会影响判断的问题。
- “画大饼”体现未来回报叙事；实际话术区分愿景与承诺，不编造收益和用途。

示例问题可以是关系中的支出要求、合作中的成果归属、自我表达与外部评价。详细输出见[回答示例](references/response-examples.md)。
